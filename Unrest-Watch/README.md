# Unrest Watch — ระบบเฝ้าระวังเหตุความไม่สงบทั่วโลก + วางแผนกักตุนเสบียง

รวบรวมข่าวเหตุความไม่สงบจากทั่วโลก → ใช้ ML คัดกรองและจัดประเภท → คำนวณความเสี่ยงต่อตำแหน่งของผู้ใช้
→ แจ้งเตือนล่วงหน้า พร้อมบอกว่าควรกักตุนอะไร เท่าไร ให้อยู่ได้กี่วัน และครบ **อาหารหลัก 5 หมู่**

```
Google News RSS (EN + TH)  ──►  ML classifier  ──►  ระบุสถานที่ + รวมข่าวซ้ำ  ──►  คะแนนความเสี่ยง  ──►  รายการกักตุน 5 หมู่
   ~600 หัวข่าว / 3 วัน        ตัดข่าวไม่เกี่ยว     (gazetteer 149 แห่ง)          ตามระยะทาง/เวลา       + ของเดิมอยู่ได้กี่วัน
                               + แยก 5 ประเภท                                                       + แจ้งเตือนมือถือ (ntfy)
```

## เริ่มใช้งาน

```bash
cd Unrest-Watch
pip install -r requirements.txt

# ดึงข่าวจริง ประเมินสำหรับบ้านที่กรุงเทพฯ ผู้ใหญ่ 2 เด็ก 1 ผู้สูงอายุ 1
python -m unrest_watch --place Bangkok --adults 2 --children 1 --elderly 1

# ใช้พิกัดเอง / ใช้ชื่อไทย
python -m unrest_watch --lat 6.87 --lon 101.25
python -m unrest_watch --place เชียงใหม่

# ของที่มีอยู่ในบ้านตอนนี้อยู่ได้กี่วัน (ดูรหัสรายการด้วย --list-items)
python -m unrest_watch --inventory inventory.example.json

# เฝ้าดูทุก 60 นาที และส่งแจ้งเตือนเข้ามือถือเมื่อระดับภัยสูงขึ้น
# (ติดตั้งแอป ntfy แล้ว subscribe หัวข้อเดียวกัน)
python -m unrest_watch --watch 60 --ntfy my-secret-topic-123

# ไม่มีเน็ต / สาธิต: ใช้ข่าวตัวอย่าง
python -m unrest_watch --offline

# วัดผลโมเดล ML
python -m unrest_watch --eval

pytest   # 46 tests
```

ตัวเลือกอื่น: `--days N` กำหนดจำนวนวันกักตุนเอง, `--json` ผลลัพธ์แบบ JSON, `--news-days` ดึงข่าวย้อนหลังกี่วัน

## ส่วน ML

**งาน:** จัดหัวข่าวเป็น 6 กลุ่ม — `none` (ไม่เกี่ยว), `protest`, `riot`, `armed_conflict`, `terrorism`, `coup`

**โมเดล:** TF-IDF character n-gram (2–5, ใช้กับภาษาไทยได้โดยไม่ต้องตัดคำ) + ฟีเจอร์คำสำคัญเฉพาะโดเมน → Logistic Regression
ตัวอย่างข่าวที่ต้องตัดทิ้ง: *"Riot Platforms stock jumps"* (หุ้น), *"Peach Riot collab at Pop Mart"* (ของเล่น), *"มวลอากาศเย็นปะทะ"* (พยากรณ์อากาศ)

**ผล 5-fold cross-validation** (หัวข่าวติดป้าย 313 ข่าว ไทย+อังกฤษ):

| โมเดล | macro-F1 | accuracy |
|---|---|---|
| char TF-IDF อย่างเดียว | 0.70 | 0.71 |
| char TF-IDF + คำสำคัญ (ใช้จริง) | **0.83** | **0.83** |

แยก "เกี่ยว/ไม่เกี่ยว" ถูก 0.88 · ประเภทที่ยากสุดคือ `coup` (F1 0.74) เพราะปนกับข่าวการเมืองทั่วไป

**ความรุนแรง (1–5):** ค่าพื้นฐานตามประเภท + บวกเพิ่มเมื่อมีผู้เสียชีวิต (ตามจำนวน)
**เหตุล่วงหน้า:** ตรวจคำบอกอนาคต เช่น *planned, this weekend, นัดชุมนุม, พรุ่งนี้* → แสดงเป็น ⏳ และไม่ลดน้ำหนักตามเวลา

## การคำนวณความเสี่ยง

แต่ละเหตุการณ์ = `0.5 × ความรุนแรง/5 × ความใกล้ × ความสด × ความมั่นใจของโมเดล × จำนวนแหล่งข่าว`

- **ความใกล้** = `exp(-ระยะจากขอบพื้นที่ / ระยะผลกระทบ)` — ประท้วง 15 กม., จลาจล/ระเบิด 40 กม., สู้รบ 150 กม., รัฐประหาร 250 กม. (และกระทบทั้งประเทศ)
- **ความสด** = `exp(-อายุข่าว(ชม.) / 36)`
- รวม 5 เหตุการณ์ที่หนักที่สุดแบบ noisy-OR (กันไม่ให้ข่าวไกลตัวหลายร้อยข่าวรวมกันเป็น "วิกฤต")

| คะแนน | ระดับ | กักตุน |
|---|---|---|
| < 20 | 🟢 ปกติ | 3 วัน |
| 20–45 | 🟡 เฝ้าระวัง | 7 วัน |
| 45–70 | 🟠 เตรียมพร้อม | 14 วัน |
| ≥ 70 | 🔴 วิกฤต | 30 วัน |

ตัวอย่างจากข่าวตัวอย่าง (`--offline`): กรุงเทพฯ 🟠 · ยะลา/แม่สอด 🟡 · เชียงใหม่/ภูเก็ต 🟢

## วางแผนเสบียง 5 หมู่

ความต้องการต่อวัน (ปัดจาก Thai DRI 2020):

| | พลังงาน | โปรตีน | คาร์บ | ไขมัน | ผัก | ผลไม้ | น้ำ |
|---|---|---|---|---|---|---|---|
| ผู้ใหญ่ | 2,000 kcal | 60 ก. | 275 ก. | 55 ก. | 3 ทัพพี | 2 ส่วน | 4 ล. |
| เด็ก | 1,400 | 40 | 195 | 40 | 2 | 2 | 3 ล. |
| ผู้สูงอายุ | 1,700 | 55 | 230 | 47 | 3 | 2 | 3.5 ล. |

- หมู่ 1 ปลากระป๋อง ทูน่า นม UHT ถั่วแห้ง ไข่ · หมู่ 2 ข้าวสาร บะหมี่ แครกเกอร์ · หมู่ 3 ผักกระป๋อง ผักดอง
  · หมู่ 4 ผลไม้กระป๋อง/อบแห้ง น้ำผลไม้ · หมู่ 5 น้ำมันพืช ถั่วลิสง · น้ำดื่ม (รวมน้ำที่ใช้หุงข้าว/ต้มถั่วแล้ว)
- ของที่อายุสั้นกว่าแผน (เช่น ไข่ 21 วัน) จะไม่ถูกใส่ในแผน 30 วัน
- `--inventory` บอกว่าของที่มีอยู่ **ครบ 5 หมู่ได้กี่วัน** (ตัวที่หมดก่อน) และ **ประทังชีวิตได้กี่วัน** (แค่พลังงาน+น้ำ)
- มี checklist ของจำเป็นอื่นตามระดับภัย (ยา ไฟฉาย เงินสด วิทยุ แผนอพยพ ฯลฯ)

## โครงสร้าง

```
unrest_watch/
  collector.py   ดึง Google News RSS 9 ชุดคำค้น (EN 5 + TH 4)
  model.py       ML classifier, ความรุนแรง, ตรวจเหตุล่วงหน้า, --eval
  geo.py         gazetteer ออฟไลน์ + ระยะทาง haversine
  pipeline.py    กรองข่าว + ระบุสถานที่ + รวมข่าวเรื่องเดียวกัน (รวมไทย/อังกฤษ)
  risk.py        คะแนนความเสี่ยงต่อตำแหน่งผู้ใช้
  supplies.py    แผนกักตุน 5 หมู่ + คำนวณของเดิมอยู่ได้กี่วัน
  cli.py         หน้าจอรายงานภาษาไทย, --watch, --ntfy
  data/          train_headlines.csv, places.csv, sample_news.json
tests/           46 tests
```

## ข้อจำกัด

- ข้อมูลฝึกมีแค่ 313 หัวข่าวที่เขียนติดป้ายเอง และคำสำคัญถูกออกแบบโดยดูข้อมูลชุดเดียวกัน ตัวเลข CV จึงน่าจะสูงกว่าความจริงบนข่าวใหม่
  ทางแก้ต่อไป: เก็บหัวข่าวจริงมาติดป้ายเพิ่ม หรือใช้ข้อมูลอย่าง ACLED / GDELT
- อ่านแค่ **หัวข่าว** ไม่ได้อ่านเนื้อข่าว · หาสถานที่ได้เฉพาะ 149 แห่งในรายการ ข่าวที่หาสถานที่ไม่เจอจะไม่ถูกนับคะแนน
- ข่าวที่พูดถึงแค่ชื่อประเทศ ถือว่าอาจเกิดที่ไหนก็ได้ในประเทศ (น้ำหนักกลาง ๆ)
- ค่าสารอาหารเป็นค่าประมาณ ใช้วางแผนเท่านั้น ไม่ใช่คำแนะนำทางการแพทย์ · คนที่มีโรคประจำตัว/ทารก ต้องเตรียมเพิ่มเอง
- **ให้ยึดประกาศของทางการเป็นหลัก** (ปภ. 1784, กระทรวงการต่างประเทศ)
