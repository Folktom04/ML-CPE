# CEFR Ladder — เกมฝึกภาษาอังกฤษ A1 → C2

เกมฝึกภาษาอังกฤษบนเว็บ ไฟล์เดียว (`index.html`) เปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## ระดับ
ครบ 6 ระดับตามกรอบ CEFR: A1, A2, B1, B2, C1, C2 (ระดับละ 24 คำศัพท์, 12 ข้อไวยากรณ์, 8 ประโยค, 2 บทอ่าน)

## โหมดฝึก
| โหมด | ทำอะไร |
|---|---|
| คำศัพท์ | A1–B1 เลือกคำแปลไทย/อังกฤษ · B2–C2 จับคู่คำกับ definition ภาษาอังกฤษ |
| ไวยากรณ์ | เติมคำในช่องว่าง พร้อมคำอธิบายภาษาไทยทุกข้อ (C1–C2 มี inversion, subjunctive, สำนวน) |
| เรียงประโยค | แตะคำเรียงให้ตรงกับคำแปล |
| ฟังแล้วพิมพ์ | เบราว์เซอร์อ่านออกเสียง แล้วพิมพ์ตาม (ไม่มีเสียง → เปลี่ยนเป็นสะกดคำ) |
| อ่านจับใจความ | อ่านบทความสั้นแล้วตอบคำถาม |
| สอบผ่านระดับ | 15 ข้อผสมทุกทักษะ ต้องได้ 12/15 เพื่อรับตรา "ผ่าน" |

## ระบบเกม
- **วัดระดับ** 15 ข้อ ปรับความยากตามคำตอบ (ตอบถูกขึ้นระดับ ตอบผิดลงระดับ)
- **หัวใจ 3 ดวง** ในรอบฝึก, **คอมโบ** เพิ่ม XP, ระดับสูงได้ XP มากกว่า
- **ทบทวนคำผิด** ข้อที่ตอบผิดถูกเก็บไว้จนกว่าจะตอบถูก
- **ความคืบหน้า** ต่อระดับ, วันติดต่อกัน (streak) บันทึกใน localStorage ของเบราว์เซอร์
- คีย์ลัด: `1`–`4` เลือกคำตอบ, `Enter` ข้อต่อไป

## เพิ่มเนื้อหา
แก้ object `DATA` ใน `index.html` ตามรูปแบบที่คอมเมนต์ไว้ด้านบน ระบบจะนับและสุ่มข้อใหม่ให้อัตโนมัติ
