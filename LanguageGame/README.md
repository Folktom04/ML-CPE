# CEFR Ladder — เกมฝึกภาษาอังกฤษ A1 → C2

เกมฝึกภาษาอังกฤษบนเว็บ ไฟล์เดียว (`index.html`) เปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## ระดับ
ครบ 6 ระดับตามกรอบ CEFR: A1, A2, B1, B2, C1, C2 ระดับละ 104 ข้อ (รวม 624 ข้อ)

## คลังคำศัพท์ Oxford 5000
คำศัพท์ 5,000 คำจาก The Oxford 3000™ และ The Oxford 5000™ (© Oxford University Press) พร้อมระดับ CEFR ตามรายการของ Oxford และคำแปลไทย
| ระดับ | A1 | A2 | B1 | B2 | C1 |
|---|---|---|---|---|---|
| จำนวนคำ | 901 | 801 | 701 | 1,300 | 1,297 |

- ค้นหาได้ทั้งอังกฤษและไทย กรองตามสถานะ (ยังไม่ฝึก / กำลังเรียน / จำได้แล้ว) และกดฟังเสียงได้
- **ฝึก 10 คำ**: เลือกความหมาย ทั้งอังกฤษ→ไทย และไทย→อังกฤษ ตัวหลอกมาจากระดับเดียวกันและชนิดคำเดียวกัน
- **ทบทวนอัตโนมัติ (spaced repetition)**: ตอบถูกแล้วจะเว้นระยะทวน 1, 3, 7, 16, 35 วัน ตอบผิดเริ่มใหม่ ถูกติดกัน 3 รอบนับว่า "จำได้แล้ว"
- ในเรื่องอ่าน แตะคำแล้วจะบอกว่าอยู่ใน Oxford 3000/5000 ระดับไหน และหน้าคำศัพท์ของเรื่องมีป้ายระดับ Oxford
- Oxford 5000 ครอบคลุมถึง C1 เท่านั้น ระดับ C2 ใช้คำศัพท์ที่คัดไว้ในโหมดคำศัพท์ของ C2

รายการคำและระดับดาวน์โหลดจาก oxfordlearnersdictionaries.com ใช้เพื่อการเรียนส่วนตัว คำแปลไทยเขียนขึ้นสำหรับเกมนี้ เป็นความหมายหลักโดยย่อ

## เรียนผ่านเรื่องอ่าน (คลังเรื่องอ่าน)
12 เรื่อง ระดับละ 2 เรื่อง ยาวขึ้นและยากขึ้นตามระดับ (A1 ราว 65–70 คำ → C2 ราว 200–220 คำ) มีทั้งเรื่องเล่า เหตุการณ์ประจำวัน บทความวิทยาศาสตร์ จิตวิทยา และเรื่องสั้น แต่ละเรื่องมี 4 แท็บ:
| แท็บ | มีอะไร |
|---|---|
| อ่าน | แตะคำไหนก็ได้เพื่อดูคำแปล ชนิดของคำ รูปเดิมของคำ (เช่น went ← go) และวลีที่มีคำนั้น · ฟังทั้งเรื่อง · เปิดคำแปลใต้ประโยคได้ |
| แปลและโครงสร้าง | ทุกประโยค: ภาษาอังกฤษ (ขีดเส้นใต้ส่วนสำคัญ) + คำแปลไทย + อธิบายการสร้างและใช้ประโยค + กฎไวยากรณ์ที่เกี่ยวข้อง |
| คำศัพท์ | คำศัพท์ทุกคำในเรื่องพร้อมชนิดของคำและคำแปล (รวมวลีและสำนวน) |
| แบบฝึก | คำถามความเข้าใจ 3 ข้อ และฝึกคำศัพท์จากเรื่อง 10 คำ (เฉลยพร้อมประโยคจากเรื่อง) |

## 4 ทักษะ 9 โหมด
| ทักษะ | โหมด | ฝึกอะไร |
|---|---|---|
| **เข้าใจ** | อ่านจับใจความ | อ่านบทความแล้วตอบคำถาม |
| | อ่านตีความ | ความหมายแฝง น้ำเสียง (ประชด, พูดอ้อม), สำนวน, สิ่งที่ไม่ได้พูดตรงๆ |
| | ฟังแล้วพิมพ์ | ฟังเสียงอ่านแล้วพิมพ์ตาม (ไม่มีเสียง → สะกดคำ) |
| **ความรู้ภาษา** | คำศัพท์ | A1–B1 คำแปลไทย/อังกฤษ · B2–C2 definition ภาษาอังกฤษ |
| | ไวยากรณ์ | เติมคำ พร้อมคำอธิบายภาษาไทย |
| | หาจุดผิด | แตะส่วนที่ผิดในประโยค แล้วดูวิธีแก้ |
| **สร้างประโยค** | เรียงประโยค | แตะคำเรียงเป็นประโยค |
| | แต่งประโยค | พิมพ์ประโยคใหม่ตามโครงสร้าง/คำที่กำหนด (B2–C2 แบบ key word transformation ของ Cambridge) รับคำตอบได้หลายแบบ และรับทั้งรูปย่อ/เต็ม เช่น didn't = did not |
| **ใช้ตามสถานการณ์** | ใช้ตามสถานการณ์ | เลือกคำพูดที่เหมาะกับสถานการณ์และระดับภาษา: ร้านอาหาร โรงแรม ที่ทำงาน สัมภาษณ์งาน อีเมลทางการ งานวิชาการ เจรจาต่อรอง แชตกับเพื่อนสนิท |

นอกจากนี้มี **ฝึกรวมทุกทักษะ** (10 ข้อ ทุกโหมด) และ **สอบผ่านระดับ** 15 ข้อครบทั้ง 4 ทักษะ (ผ่านที่ 12/15)
หน้าแต่ละระดับแสดงความคืบหน้าแยกตามทักษะ

## เมื่อตอบผิด
ข้อไวยากรณ์ หาจุดผิด แต่งประโยค เรียงประโยค และฟังประโยค (192 ข้อ) ผูกกับกฎไวยากรณ์ 41 ข้อ เมื่อตอบผิดจะเปิดแผงกฎให้เห็นทันที:
- **หมวด › ชื่อกฎ** เช่น Tenses · กาล › Present Perfect หรือ ประโยคเงื่อนไข › Third Conditional
- **โครงสร้าง** เช่น `S + have/has + V3`
- **ใช้เมื่อ** และข้อควรระวัง
- **ตัวอย่างง่ายๆ** 2–3 ประโยคที่ใช้กฎเดียวกัน พร้อมคำแปลและปุ่มฟังเสียง (สำนวนมีตัวอย่างเฉพาะข้อ)
- **ตำแหน่งในตาราง 12 tense** (อดีต/ปัจจุบัน/อนาคต × Simple/Continuous/Perfect/Perfect Continuous) รวมถึงกฎที่ใช้ tense เช่น Conditional, Reported speech, wish

ตอบถูกก็ยังกดเปิดดูกฎได้ และมี **คู่มือไวยากรณ์** จากหน้าหลัก แตะช่องในตาราง tense เพื่อเปิดกฎนั้น แต่ละกฎบอกว่าอยู่ในระดับไหนบ้าง

## ระบบเกม
- **วัดระดับ** 15 ข้อ (คำศัพท์ ไวยากรณ์ ตีความ สถานการณ์) ปรับความยากตามคำตอบ (ตอบถูกขึ้นระดับ ตอบผิดลงระดับ)
- **หัวใจ 3 ดวง** ในรอบฝึก, **คอมโบ** เพิ่ม XP, ระดับสูงได้ XP มากกว่า
- **ทบทวนคำผิด** ข้อที่ตอบผิดถูกเก็บไว้จนกว่าจะตอบถูก
- **ความคืบหน้า** ต่อระดับ, วันติดต่อกัน (streak) บันทึกใน localStorage ของเบราว์เซอร์
- คีย์ลัด: `1`–`4` เลือกคำตอบ, `Enter` ข้อต่อไป

## เพิ่มเนื้อหา
แก้ object `DATA` (คำศัพท์ ไวยากรณ์ ประโยค บทอ่าน) และ `EXTRA` (ตีความ สถานการณ์ หาจุดผิด แต่งประโยค) ใน `index.html` ตามรูปแบบที่คอมเมนต์ไว้ เรื่องอ่านอยู่ใน `STORIES` แล้วใส่ชื่อกฎของข้อใหม่ใน `TAGS` (กฎทั้งหมดอยู่ใน `RULES`) ระบบจะนับและสุ่มข้อใหม่ให้อัตโนมัติ
