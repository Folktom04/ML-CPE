# 📘 คู่มืออธิบายคำสั่งตรวจเช็คแบบละเอียด

คู่มือชุดนี้อธิบายเนื้อหาใน [Cheat Sheets](../README.md) ให้เข้าใจลึกขึ้น ทุกบทมี:
- **หลักการเบื้องหลัง** ว่าคำสั่งทำงานอย่างไร
- **ตัวอย่างผลลัพธ์จริง** พร้อมคำอธิบายทีละบรรทัด
- **ผลแบบไหนปกติ แบบไหนผิดปกติ** และต้องตรวจอะไรต่อ
- **กรณีศึกษา** และแบบฝึกหัดพร้อมเฉลย

| 2 | [Cisco IOS / IOS-XE / NX-OS](02-cisco-explained.md) | [02](../02-cisco.md) |

**แนะนำวิธีใช้:** อ่านคู่มือนี้ให้เข้าใจหนึ่งครั้ง → เวลาทำงานจริงเปิด Cheat Sheet ดูคำสั่ง → ถ้าอ่านผลไม่ออกกลับมาดูคู่มือ

> ตัวอย่างผลลัพธ์ในคู่มือเป็นข้อมูลสมมติเพื่อการเรียนรู้ (IP, serial, ชื่ออุปกรณ์) รูปแบบผลจริงอาจต่างเล็กน้อยตามรุ่นและ version ของอุปกรณ์
