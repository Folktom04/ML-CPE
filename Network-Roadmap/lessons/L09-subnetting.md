> อ่านจบแล้วจะ: แบ่ง subnet ได้ · หา Network / First / Last / Broadcast ของ IP ใด ๆ ได้ในหัวภายใน 30 วินาที · เลือก prefix ตามจำนวน host หรือจำนวน subnet ที่ต้องการได้
>
> ⭐ ทักษะนี้ถูกถามในการสัมภาษณ์งาน network แทบทุกที่

## 1. Subnetting คืออะไร ทำไมต้องทำ

**Subnetting** คือ การแบ่งเครือข่ายใหญ่ออกเป็น **เครือข่ายย่อย (subnet)** หลายวง โดย **ยืมบิตจากส่วน host มาเป็นส่วน network**

**เหตุผล:**
- **ลด broadcast:** เครื่อง 1,000 เครื่องในวงเดียว broadcast จะรบกวนกันมาก
- **ความปลอดภัย:** แยกแผนก/ประเภทอุปกรณ์ แล้วควบคุมการคุยข้ามวงที่ router/firewall
- **จัดการง่าย:** รู้ว่าวงไหนคือแผนกไหน, ไล่ปัญหาได้เร็ว
- **ใช้ IP คุ้มค่า:** ไม่ต้องให้ลิงก์ที่ใช้ 2 IP ไปกินวง /24 ทั้งวง

```
 ก่อน:  192.168.1.0/24  ──  เครื่อง 254 เครื่องทั้งบริษัทอยู่วงเดียว

 หลัง:  192.168.1.0/26   บัญชี   (62 host)
        192.168.1.64/26  HR      (62 host)
        192.168.1.128/26 IT      (62 host)
        192.168.1.192/26 Guest   (62 host)
```

---

## 2. สูตรหลัก 3 สูตร

```
 1) จำนวน subnet      = 2^(บิตที่ยืม)
 2) host ต่อ subnet    = 2^(บิต host ที่เหลือ) − 2
 3) Block size (Magic Number) = 256 − ค่า mask ใน octet ที่ "สนใจ"
    (octet ที่สนใจ = octet ที่ mask ไม่ใช่ 255 และไม่ใช่ 0)
```

**ตัวอย่าง: แบ่ง 192.168.1.0/24 เป็น /26**
- ยืม 26 − 24 = 2 บิต → subnet = 2² = **4 วง**
- บิต host เหลือ 32 − 26 = 6 → host = 2⁶ − 2 = **62 ต่อวง**
- mask /26 = 255.255.255.**192** → block = 256 − 192 = **64**
- วงจึงเริ่มที่ .0, .64, .128, .192

---

## 3. ตารางที่ต้องจำ (octet สุดท้าย)

| Prefix | Mask (octet 4) | Block size | Host ใช้ได้ | จำนวนวงใน /24 |
|---|---|---|---|---|
| /24 | 0 | 256 | 254 | 1 |
| /25 | 128 | 128 | 126 | 2 |
| /26 | 192 | 64 | 62 | 4 |
| /27 | 224 | 32 | 30 | 8 |
| /28 | 240 | 16 | 14 | 16 |
| /29 | 248 | 8 | 6 | 32 |
| /30 | 252 | 4 | 2 | 64 |
| /31 | 254 | 2 | 2* | 128 |
| /32 | 255 | 1 | 1 (host route) | 256 |

\* /31 ใช้กับลิงก์ point-to-point ระหว่าง router 2 ตัวได้ตาม RFC 3021 (ไม่มี network/broadcast)

**ตารางเดียวกันใช้กับ octet อื่นได้:** /16 /17 ... /23 เลื่อนไป octet ที่ 3, /8 ... /15 อยู่ octet ที่ 2 block size ใช้ค่าเดิม (เช่น /20 = mask 240 ใน octet 3 → block 16)

---

## 4. วิธีหา Network / First / Last / Broadcast — 4 ขั้นตอน (Magic Number)

**โจทย์: 10.1.1.130/26**

```
ขั้น 1: หา octet ที่สนใจและ block size
        /26 → octet 4, mask 192 → block = 256 − 192 = 64

ขั้น 2: ไล่ผลคูณของ block ใน octet ที่สนใจ: 0, 64, 128, 192, (256)
        IP ใน octet 4 = 130 → อยู่ระหว่าง 128 กับ 192
        → Network = 10.1.1.128

ขั้น 3: Broadcast = (network ถัดไป) − 1 = 192 − 1
        → Broadcast = 10.1.1.191

ขั้น 4: First host = network + 1 = 10.1.1.129
        Last host  = broadcast − 1 = 10.1.1.190
```

**ผลลัพธ์**
| | |
|---|---|
| Network | 10.1.1.128 |
| First usable | 10.1.1.129 |
| Last usable | 10.1.1.190 |
| Broadcast | 10.1.1.191 |
| Hosts | 62 |

## 5. ตัวอย่างที่ octet ไม่ใช่ตัวสุดท้าย

**โจทย์: 172.16.45.200/20**

```
/20 → octet 3 (เพราะ 16 < 20 < 24), บิต network ใน octet 3 = 20 − 16 = 4 บิต
mask octet 3 = 240 → block = 16
ผลคูณ 16 ใน octet 3: 0, 16, 32, 48 ...  → 45 อยู่ระหว่าง 32 กับ 48

Network   = 172.16.32.0         (octet หลัง octet ที่สนใจ = 0)
Broadcast = 172.16.47.255       (network ถัดไป 48 − 1 = 47, octet หลัง = 255)
First     = 172.16.32.1
Last      = 172.16.47.254
Hosts     = 2^12 − 2 = 4,094
```

**โจทย์: 10.50.100.1/13**
```
/13 → octet 2, บิตใน octet 2 = 5 → mask 248 → block 8
ผลคูณ 8: ..., 48, 56 → 50 อยู่ระหว่าง 48 กับ 56
Network = 10.48.0.0 · Broadcast = 10.55.255.255
```

---

## 6. เลือก Prefix จาก "จำนวน host ที่ต้องการ"

**วิธี:** หา 2ⁿ − 2 ที่ ≥ จำนวน host แล้ว prefix = 32 − n

| ต้องการ host | n | Prefix | ได้จริง |
|---|---|---|---|
| 10 | 4 (16−2=14) | /28 | 14 |
| 25 | 5 (32−2=30) | /27 | 30 |
| 50 | 6 (64−2=62) | /26 | 62 |
| 100 | 7 (128−2=126) | /25 | 126 |
| 200 | 8 (256−2=254) | /24 | 254 |
| 500 | 9 (512−2=510) | /23 | 510 |
| 1,000 | 10 (1024−2=1022) | /22 | 1,022 |

> 🏢 **ในงานจริง:** เผื่อการเติบโตไว้ 30–50% เช่น แผนกมี 40 คน แต่ละคนมีคอม+มือถือ+IP phone ควรคิดเป็นอุปกรณ์ ~120 แล้วเลือก /25

## 7. เลือก Prefix จาก "จำนวน subnet ที่ต้องการ"

**วิธี:** หา 2ⁿ ≥ จำนวน subnet → ยืม n บิต

**โจทย์: ต้องการ 6 subnet จาก 192.168.5.0/24**
```
2² = 4 ไม่พอ · 2³ = 8 ≥ 6 → ยืม 3 บิต → /27
host ต่อวง = 2⁵ − 2 = 30
วง: .0, .32, .64, .96, .128, .160, .192, .224 (8 วง ใช้ 6 เหลือ 2 สำรอง)
```

---

## 8. ตรวจว่า 2 IP อยู่วงเดียวกันไหม

**โจทย์: 192.168.1.64/27 กับ 192.168.1.90 อยู่วงเดียวกันหรือไม่**
```
/27 block 32 → วง .64 – .95 → 90 อยู่ในช่วง → อยู่วงเดียวกัน ✅
```

**โจทย์: 10.0.0.62/26 กับ 10.0.0.65/26**
```
block 64 → .62 อยู่วง .0–.63 · .65 อยู่วง .64–.127 → คนละวง ❌ (ต้องผ่าน router)
```

## 9. ตัวช่วยตรวจคำตอบ

```python
import ipaddress
n = ipaddress.ip_interface("10.1.1.130/26").network
print(n.network_address, n.broadcast_address, n.num_addresses - 2)
# 10.1.1.128 10.1.1.191 62
list(ipaddress.ip_network("192.168.1.0/24").subnets(new_prefix=26))
```
Linux: `ipcalc 10.1.1.130/26` · เว็บ: subnet calculator ทั่วไป
> ⚠️ ใช้เครื่องมือเพื่อตรวจคำตอบเท่านั้น ในการสอบ/สัมภาษณ์ต้องคิดเองได้

## 10. วิธีฝึกให้เร็ว (เป้าหมาย < 30 วินาทีต่อข้อ)

1. จำตาราง block size ในข้อ 3 ให้ขึ้นใจ
2. ฝึกขั้นตอน 4 ขั้นในข้อ 4 วันละ 20 ข้อ (subnettingpractice.com หรือสุ่มเอง)
3. เริ่มจาก /24–/30 ก่อน แล้วค่อยขยับไป /16–/23 และ /8–/15
4. ตรวจด้วย Python/ipcalc ทุกข้อ

---

## 11. เรื่องที่คนมักเข้าใจผิด

| ❌ | ✅ |
|---|---|
| block size คือจำนวน host ใช้ได้ | block size = จำนวน IP ทั้งหมดในวง; ใช้ได้ = block − 2 |
| Network address ใช้ตั้งให้เครื่องได้ | ใช้ไม่ได้ (ยกเว้นกรณี /31, /32) |
| /20 คิดที่ octet สุดท้าย | /17–/23 คิดที่ octet ที่ 3 |
| แบ่งให้วงเริ่มตรงไหนก็ได้ | วงต้องเริ่มที่ผลคูณของ block size เท่านั้น |

## 12. Cheat Sheet

```
Subnet = 2^ยืม · Host = 2^เหลือ − 2 · Block = 256 − mask(octet ที่สนใจ)
/25 128 · /26 64 · /27 32 · /28 16 · /29 8 · /30 4 (block)
ขั้นตอน: block → ผลคูณที่ ≤ IP = Network → Network ถัดไป −1 = Broadcast → ±1 = First/Last
/17-/23 คิด octet 3 · /9-/15 คิด octet 2 · octet หลังจากนั้น network=0 broadcast=255
```
