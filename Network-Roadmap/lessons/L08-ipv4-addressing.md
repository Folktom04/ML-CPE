# บทเรียน Level 8 — IPv4 Addressing (ฉบับละเอียด)

> อ่านจบแล้วจะ: อ่าน IP + subnet mask ได้ · แยก network/host · รู้จัก Private, Public และ IP พิเศษ · เข้าใจ default gateway · คำนวณจำนวน host ได้

---

## 1. IPv4 Address คืออะไร

**IP Address** คือ **ที่อยู่เชิงตรรกะ (Layer 3)** ของอุปกรณ์ ใช้ส่งข้อมูล **ข้ามเครือข่าย** ไปถึงปลายทาง

- **IPv4** ยาว **32 บิต** แบ่งเป็น 4 octet เขียนเป็นเลขฐาน 10 คั่นด้วยจุด (dotted decimal)
```
   192   .  168   .   1    .   10
 11000000.10101000.00000001.00001010
```
- แต่ละ octet มีค่า 0–255 → มี IPv4 ทั้งหมด 2³² ≈ **4.3 พันล้าน** หมายเลข

> 💡 **IP vs MAC:** IP = ที่อยู่บ้าน (เปลี่ยนเมื่อย้ายเครือข่าย ใช้หาเส้นทาง) · MAC = เลขบัตรประชาชนของการ์ด (ใช้ส่งภายในเครือข่ายเดียวกัน)

---

## 2. Network Portion + Host Portion

IP แต่ละตัวแบ่งเป็น 2 ส่วน
- **Network portion:** บอกว่าอยู่ **เครือข่ายไหน** (เหมือนชื่อถนน)
- **Host portion:** บอกว่าเป็น **เครื่องไหน** ในเครือข่ายนั้น (เหมือนบ้านเลขที่)

**Subnet Mask** คือตัวบอกว่าบิตไหนเป็น network (บิต 1) บิตไหนเป็น host (บิต 0)

```
 IP:    192.168.1.10     11000000.10101000.00000001.00001010
 Mask:  255.255.255.0    11111111.11111111.11111111.00000000
                         └──────── Network (24 บิต) ──────┘└ Host 8 ┘
```

### CIDR Notation
เขียน mask แบบสั้นด้วยจำนวนบิต 1: **192.168.1.10/24** = mask 255.255.255.0

| CIDR | Mask | CIDR | Mask |
|---|---|---|---|
| /8 | 255.0.0.0 | /25 | 255.255.255.128 |
| /16 | 255.255.0.0 | /26 | 255.255.255.192 |
| /20 | 255.255.240.0 | /27 | 255.255.255.224 |
| /22 | 255.255.252.0 | /28 | 255.255.255.240 |
| /23 | 255.255.254.0 | /29 | 255.255.255.248 |
| /24 | 255.255.255.0 | /30 | 255.255.255.252 |

---

## 3. ที่อยู่พิเศษในแต่ละเครือข่าย

ทุก subnet มี 2 หมายเลขที่ **ให้เครื่องใช้ไม่ได้**

| ชนิด | ลักษณะ | ตัวอย่าง (192.168.1.0/24) |
|---|---|---|
| **Network Address** | บิต host เป็น 0 ทั้งหมด (ชื่อของเครือข่าย) | **192.168.1.0** |
| **Broadcast Address** | บิต host เป็น 1 ทั้งหมด (ส่งถึงทุกคนในวง) | **192.168.1.255** |
| **Usable Host** | ที่เหลือ | 192.168.1.1 – 192.168.1.254 |

**สูตรจำนวน host ที่ใช้ได้ = 2^(บิต host) − 2**
- /24 → host 8 บิต → 2⁸ − 2 = **254**
- /26 → host 6 บิต → 2⁶ − 2 = **62**
- /30 → host 2 บิต → 2² − 2 = **2** (ใช้กับลิงก์ระหว่าง router 2 ตัว)

---

## 4. Default Gateway

**Default Gateway** คือ IP ของ router ในเครือข่ายเดียวกัน ที่เครื่องจะส่งข้อมูลไปให้ **เมื่อปลายทางอยู่นอกเครือข่ายตัวเอง**

```
 เครื่อง A: 192.168.1.10/24 · Gateway 192.168.1.1

 ส่งถึง 192.168.1.50 → อยู่วงเดียวกัน (AND กับ mask ได้ 192.168.1.0 เหมือนกัน) → ส่งตรงด้วย ARP
 ส่งถึง 8.8.8.8      → อยู่นอกวง → ส่งให้ gateway 192.168.1.1 ไปจัดการต่อ
```

- ถ้าไม่ได้ตั้ง gateway: คุยในวงเดียวกันได้ แต่ **ออกนอกวง/อินเทอร์เน็ตไม่ได้**
- gateway ต้องอยู่ **ในวงเดียวกัน** กับเครื่อง
- โดยธรรมเนียมนิยมใช้ IP แรก (.1) หรือ IP สุดท้าย (.254) ของวงเป็น gateway

**การตั้งค่า IP ของเครื่องหนึ่งเครื่องจึงมี 4 อย่าง:** IP address, Subnet mask, Default gateway, DNS server

---

## 5. Classful Addressing (ประวัติศาสตร์ที่ยังถูกถาม)

ระบบเดิมแบ่ง IP เป็นคลาสตามค่า octet แรก

| Class | Octet แรก | Default mask | ใช้ทำอะไร |
|---|---|---|---|
| A | 1–126 | /8 | เครือข่ายขนาดใหญ่มาก |
| B | 128–191 | /16 | ขนาดกลาง |
| C | 192–223 | /24 | ขนาดเล็ก |
| D | 224–239 | — | Multicast |
| E | 240–255 | — | สงวนไว้ทดลอง |

(127.x.x.x สงวนไว้สำหรับ loopback)

ปัจจุบันใช้ **Classless (CIDR)** กำหนด mask ได้อิสระ ไม่ผูกกับคลาสแล้ว แต่คำว่า "Class C" ยังถูกใช้เรียกวง /24 ในการพูดทั่วไป

## 6. Private IP vs Public IP

### Private IP (RFC 1918) — ใช้ภายในองค์กร/บ้าน ไม่ถูก route บนอินเทอร์เน็ต

| ช่วง | CIDR | จำนวน IP |
|---|---|---|
| 10.0.0.0 – 10.255.255.255 | **10.0.0.0/8** | ~16.7 ล้าน |
| 172.16.0.0 – 172.31.255.255 | **172.16.0.0/12** | ~1 ล้าน |
| 192.168.0.0 – 192.168.255.255 | **192.168.0.0/16** | 65,536 |

- ใครจะใช้ซ้ำกันก็ได้ เพราะใช้แค่ภายใน
- จะออกอินเทอร์เน็ตได้ต้องผ่าน **NAT** แปลงเป็น Public IP (Level 17)

### Public IP
- ไม่ซ้ำกันทั่วโลก ได้รับจัดสรรจาก ISP/RIR (APNIC)
- ใช้กับ server ที่ต้องให้คนภายนอกเข้าถึง, ขา WAN ของ router

## 7. IP พิเศษที่ต้องรู้

| ช่วง/ค่า | ความหมาย | เจอเมื่อไร |
|---|---|---|
| **127.0.0.0/8** (127.0.0.1) | **Loopback** — ตัวเครื่องเอง | ทดสอบ TCP/IP stack, เข้าบริการบนเครื่องตัวเอง (localhost) |
| **169.254.0.0/16** | **APIPA / Link-local** | เครื่องขอ IP จาก DHCP ไม่ได้ จึงตั้งเอง → **สัญญาณว่า DHCP มีปัญหา** |
| **100.64.0.0/10** | **CGNAT (Shared Address Space)** | ISP ใช้ทำ NAT อีกชั้น ลูกค้าไม่ได้ public IP จริง |
| **0.0.0.0** | "ทุก/ไม่ระบุ" | เครื่องยังไม่มี IP, default route (0.0.0.0/0), บริการ listen ทุก interface |
| **255.255.255.255** | Limited broadcast | broadcast ในวงตัวเอง (เช่น DHCP Discover) |
| **224.0.0.0/4** | Multicast | วิดีโอสด, routing protocol (OSPF 224.0.0.5) |
| 192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24 | สำหรับเอกสาร/ตัวอย่าง | ใช้ในตำรา (ไม่ใช้จริง) |

## 8. ประเภทการส่ง (ตามผู้รับ)

| ประเภท | ผู้รับ | ตัวอย่าง |
|---|---|---|
| **Unicast** | เครื่องเดียว | เปิดเว็บ |
| **Broadcast** | ทุกเครื่องในวง | DHCP Discover, ARP request |
| **Multicast** | กลุ่มที่สมัครรับ | IPTV, OSPF |
| (Anycast) | เครื่องที่ใกล้ที่สุดในกลุ่มที่ใช้ IP เดียวกัน | DNS 8.8.8.8 / 1.1.1.1, CDN |

## 9. Static vs Dynamic IP

| | Static (ตั้งเอง) | Dynamic (DHCP) |
|---|---|---|
| ตั้งค่า | ตั้งที่เครื่องด้วยมือ | ได้รับอัตโนมัติจาก DHCP server |
| เหมาะกับ | Server, router, switch, printer, กล้อง | PC, โน้ตบุ๊ก, มือถือ |
| ความเสี่ยง | ตั้งซ้ำกันได้ (IP conflict) ถ้าไม่มีทะเบียน | ถ้า DHCP ล่ม เครื่องใหม่ได้ 169.254.x.x |

ทางเลือกกลาง: **DHCP Reservation** จองให้เครื่องหนึ่งได้ IP เดิมเสมอผ่าน DHCP

> 🏢 **ในงานจริง:** ทุกองค์กรต้องมี **IPAM / ทะเบียน IP** (อย่างน้อยเป็น spreadsheet) ระบุว่า subnet ไหนใช้ทำอะไร ใครถือ IP อะไร เพื่อป้องกัน IP ชนกัน

## 10. ดู/ตั้ง IP บนเครื่อง


## 11. ตัวอย่างวิเคราะห์

**เครื่องได้ IP 192.168.1.130/25 gateway 192.168.1.1 เข้าเน็ตไม่ได้ เพราะอะไร?**
```
/25 → block 128 → วงของเครื่อง: 192.168.1.128 – 192.168.1.255
gateway 192.168.1.1 อยู่วง 192.168.1.0 – 127 → คนละวง!
เครื่องจึงส่งหา gateway ไม่ได้ → ต้องแก้ gateway ให้อยู่ในวงเดียวกัน หรือแก้ mask
```

## 12. เรื่องที่คนมักเข้าใจผิด

| ❌ | ✅ |
|---|---|
| /24 ใช้ได้ 256 เครื่อง | ใช้ได้ **254** (หัก network + broadcast) |
| 172.32.1.1 เป็น private | private ของ 172 คือ **172.16–172.31** เท่านั้น |
| ได้ 169.254.x.x แปลว่าเน็ตใช้ได้ | แปลว่า **ไม่ได้ IP จาก DHCP** |
| gateway อยู่วงไหนก็ได้ | ต้องอยู่วงเดียวกับเครื่อง |
| IP ระบุตัวคนได้แน่นอน | หลายเครื่องอาจใช้ public IP เดียวกันผ่าน NAT/CGNAT |

## 13. Cheat Sheet

```
IPv4 = 32 บิต = 4 octet (0-255) · Network + Host แบ่งด้วย mask/CIDR
Usable host = 2^(32-prefix) - 2 · Network = host bits 0 · Broadcast = host bits 1
ตั้งค่าเครื่อง = IP + Mask + Gateway + DNS · Gateway ต้องอยู่วงเดียวกัน
Private: 10/8 · 172.16/12 (16-31) · 192.168/16
พิเศษ: 127/8 loopback · 169.254/16 APIPA (DHCP พัง) · 100.64/10 CGNAT · 224/4 multicast
Classful: A 1-126 /8 · B 128-191 /16 · C 192-223 /24 · D multicast · E สงวน
```
