# บทเรียน Level 18 — IPv6 พื้นฐาน (ฉบับละเอียด)

> อ่านจบแล้วจะ: อ่าน/ย่อ/ขยาย IPv6 ได้ · แยกประเภท address ได้ · เข้าใจความต่างจาก IPv4 (ไม่มี broadcast, ไม่มี NAT, header ใหม่) · รู้วิธีเปลี่ยนผ่าน: Dual-stack, Tunnel, NAT64

---

## 1. ทำไมต้องมี IPv6

- IPv4 มี 2³² ≈ 4.3 พันล้าน address **หมดแล้ว** (IANA แจก block สุดท้ายปี 2011, APNIC หมดในปีเดียวกัน)
- NAT/CGNAT เป็นเพียงทางแก้ชั่วคราวที่สร้างปัญหาอื่นตามมา
- **IPv6 มี 2¹²⁸ ≈ 3.4 × 10³⁸ address** มากพอให้ทุกอุปกรณ์มี global address ของตัวเอง

> 💡 ถ้า IPv4 ทั้งหมดเท่ากับลูกกอล์ฟ 1 ลูก IPv6 จะมีขนาดประมาณดวงอาทิตย์

ผู้ให้บริการมือถือและเน็ตบ้านในไทยหลายรายให้ IPv6 แล้ว และหน่วยงานรัฐมักกำหนดใน TOR ว่าอุปกรณ์ต้องรองรับ IPv6

---

## 2. รูปแบบการเขียน

- 128 บิต แบ่ง **8 กลุ่ม (hextet) กลุ่มละ 16 บิต** เขียนเป็น hex 4 ตัว คั่นด้วย `:`

```
 2001:0db8:0000:0000:0000:ff00:0042:8329
```

### กฎการย่อ 2 ข้อ
1. **ตัด 0 นำหน้า** ในแต่ละกลุ่ม: `0db8` → `db8`, `0042` → `42`, `0000` → `0`
2. **แทนกลุ่ม 0 ที่ติดกันด้วย `::` ได้เพียงครั้งเดียว** (ถ้ามีหลายช่วงให้ย่อช่วงที่ยาวที่สุด หากเท่ากันให้ย่อช่วงแรก)

```
 2001:0db8:0000:0000:0000:ff00:0042:8329
 → 2001:db8:0:0:0:ff00:42:8329        (กฎ 1)
 → 2001:db8::ff00:42:8329             (กฎ 2)
```

**ตัวอย่างเพิ่มเติม**

| เต็ม | ย่อ |
|---|---|
| `fe80:0000:0000:0000:0204:61ff:fe9d:f156` | `fe80::204:61ff:fe9d:f156` |
| `0000:0000:0000:0000:0000:0000:0000:0001` | `::1` |
| `0000:...:0000` (ทั้งหมด) | `::` |
| `2001:0db8:0000:0001:0000:0000:0000:0001` | `2001:db8:0:1::1` |

> ⚠️ ใช้ `::` สองครั้งไม่ได้ เช่น `2001::1::5` ผิด เพราะไม่รู้ว่าแต่ละช่วงมี 0 กี่กลุ่ม

### Prefix
ใช้ CIDR เหมือน IPv4 เช่น `2001:db8:abcd:12::/64`
- **ISP ให้ site/องค์กร:** มัก /48 หรือ /56 (บ้านอาจได้ /56 หรือ /64)
- **ทุก LAN/VLAN ใช้ /64** (มาตรฐาน — SLAAC ต้องการ 64 บิตสำหรับ interface ID)
- /48 แบ่งเป็น /64 ได้ 2¹⁶ = **65,536 วง**

```
 2001:db8:abcd : 0012 : 0000:0000:0000:0001
 └─ Global routing prefix (/48) ─┘└Subnet ID┘└─── Interface ID (64 บิต) ───┘
         จาก ISP                    องค์กรแบ่งเอง        ระบุเครื่อง
```

## 3. ประเภทของ IPv6 Address

| ประเภท | Prefix | ความหมาย | เทียบ IPv4 |
|---|---|---|---|
| **Global Unicast (GUA)** | **2000::/3** (ขึ้นต้น 2 หรือ 3) | address สาธารณะ route บนอินเทอร์เน็ตได้ | Public IP |
| **Link-Local** | **fe80::/10** | ใช้ได้เฉพาะในลิงก์เดียว **ทุก interface มีเสมอ** สร้างอัตโนมัติ ใช้คุยกับเพื่อนบ้านและ router (เช่น เป็น next-hop) | คล้าย 169.254 แต่ใช้จริงตลอด |
| **Unique Local (ULA)** | **fc00::/7** (ใช้จริง fd00::/8) | ใช้ภายในองค์กร ไม่ route บนอินเทอร์เน็ต | Private IP (RFC 1918) |
| **Loopback** | **::1/128** | ตัวเครื่องเอง | 127.0.0.1 |
| **Unspecified** | **::/128** | ยังไม่มี address | 0.0.0.0 |
| **Multicast** | **ff00::/8** | ส่งถึงกลุ่ม | 224.0.0.0/4 |
| **Anycast** | (ใช้รูปแบบ unicast) | หลายเครื่องใช้ address เดียว ส่งถึงตัวที่ใกล้ที่สุด | — |
| IPv4-mapped | ::ffff:0:0/96 | แทน IPv4 ในโปรแกรม IPv6 เช่น `::ffff:192.0.2.1` | — |
| เอกสาร/ตัวอย่าง | 2001:db8::/32 | ใช้ในตำรา | 192.0.2.0/24 |

**Multicast ที่ต้องรู้**

| Address | กลุ่ม |
|---|---|
| `ff02::1` | All nodes (ทุกเครื่องในลิงก์) — ใช้แทน broadcast |
| `ff02::2` | All routers |
| `ff02::1:ffXX:XXXX` | Solicited-node (ใช้ใน NDP แทน ARP) |
| `ff02::5`, `ff02::6` | OSPFv3 |

> 💡 **interface เดียวมีหลาย IPv6 พร้อมกันเป็นเรื่องปกติ:** link-local + global (บางครั้งมีหลายตัว เช่น temporary/privacy address) + multicast หลายกลุ่ม

## 4. IPv6 ต่างจาก IPv4 อย่างไร

| หัวข้อ | IPv4 | IPv6 |
|---|---|---|
| ขนาด address | 32 บิต | **128 บิต** |
| Broadcast | มี | **ไม่มี** (ใช้ multicast) |
| ARP | ใช้ ARP | **NDP** (ICMPv6) |
| การได้ address | DHCP / static | **SLAAC**, DHCPv6, static |
| NAT | ใช้แพร่หลาย | **ไม่จำเป็น** (ใช้ firewall แทน) |
| Header | ขนาดแปรผัน มี checksum | **ขนาดคงที่ 40 ไบต์**, ไม่มี checksum (ชั้นอื่นตรวจแล้ว), ใช้ extension headers |
| Fragmentation | router แบ่งได้ | **เฉพาะต้นทาง** (router ไม่แบ่ง ใช้ PMTUD — ห้าม block ICMPv6!) |
| MTU ขั้นต่ำ | 576 | **1280** |
| ICMP | เสริม | **จำเป็น** (NDP, PMTUD พึ่ง ICMPv6) |
| IPsec | เสริม | ออกแบบมารองรับ (แต่ไม่บังคับใช้) |
| field TTL | TTL | **Hop Limit** |

### IPv6 Header (40 ไบต์)
```
 Version(4) | Traffic Class(8) | Flow Label(20)
 Payload Length(16) | Next Header(8) | Hop Limit(8)
 Source Address (128)
 Destination Address (128)
```
ออกแบบให้เรียบง่ายเพื่อให้ router ประมวลผลได้เร็ว

## 5. การเปลี่ยนผ่านจาก IPv4 → IPv6

| วิธี | หลักการ | ใช้เมื่อ |
|---|---|---|
| **Dual-Stack** | อุปกรณ์รันทั้ง IPv4 และ IPv6 พร้อมกัน ใช้อันไหนก็ได้ตามปลายทาง (มักเลือก IPv6 ก่อน — Happy Eyeballs) | **วิธีหลักในองค์กร** |
| **Tunneling** | ห่อ IPv6 ใน IPv4 (6in4, GRE) เพื่อข้ามเครือข่ายที่มีแต่ IPv4 | เชื่อมเกาะ IPv6 ระหว่างกัน |
| **Translation (NAT64 + DNS64)** | เครือข่ายมีแต่ IPv6 แปลงเพื่อเข้าถึงเว็บ IPv4 | ผู้ให้บริการมือถือ, เครือข่าย IPv6-only |

## 6. คำสั่งที่ใช้

```bash
ipconfig                                 # Windows: ดู IPv6 address, link-local (%12 = zone/interface)
ip -6 addr ; ip -6 route                 # Linux
ping -6 2001:4860:4860::8888             # Windows
ping 2001:4860:4860::8888                # Linux (ping6 ในรุ่นเก่า)
ping fe80::1%eth0                        # link-local ต้องระบุ interface
traceroute -6 google.com
curl -6 https://ifconfig.co              # ทดสอบว่าออกเน็ตด้วย IPv6 ได้
```
- เว็บทดสอบ: test-ipv6.com
- **Zone ID (`%eth0`, `%12`):** link-local ทุก interface ขึ้นต้น fe80 เหมือนกัน จึงต้องบอกว่าใช้ interface ไหน
- ใน URL ต้องใส่วงเล็บเหลี่ยม: `http://[2001:db8::1]:8080/`

## 7. ความปลอดภัยของ IPv6 ที่มักถูกมองข้าม

- **เครื่องส่วนใหญ่เปิด IPv6 อยู่แล้ว** แม้องค์กรคิดว่า "ยังไม่ได้ใช้" → ผู้โจมตีอาจใช้ IPv6 ในเครือข่ายภายใน (เช่น ปล่อย Router Advertisement ปลอม) → ต้องมีนโยบาย: ใช้อย่างตั้งใจและควบคุม หรือควบคุมด้วย RA Guard
- Firewall ต้องมี **policy สำหรับ IPv6 แยก** — กฎของ IPv4 ไม่ครอบคลุม IPv6
- **อย่า block ICMPv6 ทั้งหมด** (NDP, PMTUD จะพัง)
- ไม่มี NAT ไม่ได้แปลว่าไม่ปลอดภัย — ใช้ stateful firewall อนุญาตเฉพาะขาออกและการตอบกลับ (เหมือนผลที่ได้จาก NAT)

## 8. เรื่องที่คนมักเข้าใจผิด

| ❌ | ✅ |
|---|---|
| ใช้ `::` ได้หลายครั้ง | ได้ครั้งเดียว |
| IPv6 ต้องมี NAT เหมือน IPv4 | ไม่จำเป็น ใช้ firewall ควบคุม |
| ไม่ได้ตั้ง IPv6 = ไม่มี IPv6 | ทุก interface มี link-local อัตโนมัติ และอาจได้ global จาก RA |
| LAN IPv6 ควรใช้ /120 ให้ประหยัด | ใช้ /64 ตามมาตรฐาน (SLAAC ต้องการ) |
| IPv6 มี broadcast | ไม่มี ใช้ multicast ff02::1 |

## 9. Cheat Sheet

```
IPv6 = 128 บิต · 8 กลุ่ม × 16 บิต · hex
ย่อ: ตัด 0 นำหน้า · :: แทนกลุ่ม 0 ติดกัน "ครั้งเดียว"
GUA 2000::/3 · Link-local fe80::/10 (มีเสมอ) · ULA fc00::/7 (fd..)
Loopback ::1 · Unspecified :: · Multicast ff00::/8 (ff02::1 all nodes, ff02::2 routers)
LAN = /64 เสมอ · site /48 = 65,536 subnet
ไม่มี broadcast · ไม่มี ARP (ใช้ NDP) · ไม่จำเป็นต้อง NAT · router ไม่ fragment
Header 40B · Hop Limit · MTU ขั้นต่ำ 1280 · ห้าม block ICMPv6
เปลี่ยนผ่าน: Dual-stack (หลัก) · Tunnel · NAT64/DNS64
```

## 10. แบบทดสอบ 10 ข้อ

1. IPv6 มีกี่บิต แบ่งเป็นกี่กลุ่ม
2. ย่อ `2001:0db8:0000:0000:0000:ff00:0042:8329`
3. ขยาย `2001:db8::1` ให้เต็ม 8 กลุ่ม
4. `fe80::1` คือ address ประเภทใด และใช้ทำอะไร
5. Address ใดของ IPv6 เทียบได้กับ private IP ของ IPv4
6. IPv6 ใช้อะไรแทน broadcast และแทน ARP
7. ทำไม LAN ของ IPv6 ควรใช้ /64
8. องค์กรได้ /48 จาก ISP แบ่ง /64 ได้กี่วง
9. Dual-stack คืออะไร
10. ทำไมไม่ควร block ICMPv6 ทั้งหมดที่ firewall

1. 128 บิต, 8 กลุ่ม (กลุ่มละ 16 บิต)
2. `2001:db8::ff00:42:8329`

4. Link-local — ใช้สื่อสารภายในลิงก์เดียว (NDP, next-hop ของ routing) ทุก interface มีเสมอ
5. ULA (fc00::/7 ใช้จริง fd00::/8)
