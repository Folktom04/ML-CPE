## 1. ภาพรวมบริษัท

| หัวข้อ | รายละเอียดจากเว็บไซต์ |
|---|---|
| ก่อตั้ง | ปี 1997 โดยกลุ่มวิศวกรอาวุโสชาวไทย (ประสบการณ์ 25+ ปี) |
| ตำแหน่งในตลาด | ผู้ให้บริการและที่ปรึกษาด้านเทคโนโลยีสารสนเทศ โครงสร้างพื้นฐานไอที และความมั่นคงปลอดภัยไซเบอร์ (System Integrator + Consultant + IT Outsourcing) |
| วิสัยทัศน์ | เป็นผู้นำและที่ปรึกษาด้านโครงสร้างพื้นฐานเทคโนโลยีสารสนเทศที่ได้รับความไว้วางใจสูงสุดจากองค์กรชั้นนำ |
| พันธกิจ | ส่งมอบโซลูชันระบบไอทีที่มีเสถียรภาพ ปลอดภัย และยืดหยุ่นสูง เพื่อให้ธุรกิจลูกค้าดำเนินไปอย่างต่อเนื่องไม่มีสะดุด |
| ค่านิยม | ความซื่อสัตย์, ความเป็นมืออาชีพ, ความสำเร็จของลูกค้า, การพัฒนาทักษะเทคโนโลยีอย่างต่อเนื่อง |
| มาตรฐาน | ISO 9001:2015 (Quality Management); โครงการ security อ้างอิง ISO/IEC 27001 |
| ลูกค้า | 100+ องค์กร: กระทรวง ทบวง กรม, โรงพยาบาลชั้นนำ, ภาคเอกชนระดับประเทศ |
| บริการหลังการขาย | Hotline 24x7x365, SLA onsite ภายใน 2 ชั่วโมง (สูงสุด), PM รายไตรมาส, eSupport ticket |

**ผลลัพธ์ที่บริษัทระบุ:** ระบบต้องเสถียร ปลอดภัย และคุ้มค่า ทำงานต่อเนื่องได้ ไม่มี Single Point of Failure, งานส่งมอบตรงเวลาพร้อมเอกสาร และผ่าน UAT ก่อนส่งมอบ
