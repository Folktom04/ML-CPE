# 🏢 ISC-Track: Level 1–100 ตามขอบเขตงานของ ISC

หลักสูตรนี้จัด Level 1–100 ตาม **ขอบเขตงานจริงของ ISC (Information Service and Consultant Co., Ltd.)** ที่ถอดจากเว็บไซต์ isc-th.com
รายละเอียดการถอดขอบเขต (บริการ, แบรนด์, certificate, ผลงาน, ตำแหน่งงาน) อยู่ใน **[00-isc-scope.md](00-isc-scope.md)**

- Level ที่มีเนื้อหาอยู่แล้วใน [Roadmap หลัก](../README.md) หรือ [SI-Track](../SI-Track/README.md) จะลิงก์ไปเรียนจากต้นทาง และเพิ่ม **ISC Checkpoint** สำหรับงานของ ISC
- Level ที่เป็น **🆕 เนื้อหาใหม่** (บริการของ ISC ที่ track เดิมยังไม่ครอบคลุม) มีครบทั้งสิ่งที่ต้องรู้ แบบทดสอบ 5 ข้อพร้อมเฉลย และ 5 โปรเจค
- **Capstone** ใช้โจทย์จาก **ผลงานจริงของ ISC** (PFO-DC-01, PFO-VIRT-02, PFO-SEC-03, PFO-DR-04)

## 🎯 ลำดับการเรียนตามตำแหน่งงานที่ ISC เปิดรับ

| ตำแหน่ง | ลำดับที่แนะนำ |
|---|---|
| **Network & Security Engineer** (CCNA / Fortinet) | 1–20 → 44–56 → 88–94 → 99 |
| **Senior System Engineer (Infrastructure & Cloud)** (MCP / VCP) | 1–8 → 21–43 → 57–73 → 88–97 → 99 |
| IT Outsourcing / Onsite Engineer | 1–8 → 21–24 → 74–77 → 88–95 |
| Data / AI Infrastructure Engineer | 1–8 → 21–30 → 78–87 |
| Pre-sales / Solution Architect / PM | ทำครบ โดยเน้น 20, 36, 38, 56, 62, 96–97, 100 |

## ✅ เกณฑ์ผ่าน

- **Level ใหม่:** ทำแบบทดสอบได้ ≥ 4/5 ข้อ และทำโปรเจคอย่างน้อย 3 ชิ้น (ในนั้นต้องมี ⭐⭐ ขึ้นไป 1 ชิ้น)
- **Level ที่ลิงก์:** ผ่านเกณฑ์ของ Level ต้นทาง และตอบ ISC Checkpoint ได้
- **Capstone (20, 38, 43, 56, 62, 82-P5, 87-P5, 100):** ทำครบ 5 ระยะ และตอบ self-review ได้ทุกข้อ
