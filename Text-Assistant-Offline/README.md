# ผู้ช่วยภาษา ออฟไลน์ (Offline Thai Text Assistant)

ระบบช่วยเขียนภาษาไทยที่ทำงานบนเครื่องของเราเองทั้งหมด **ไม่ต้องใช้อินเทอร์เน็ต** และไม่ส่งข้อความไปที่ใด

| ความสามารถ | รายละเอียด |
|---|---|
| 1. แก้คำผิด | แก้คำสะกดผิด พิมพ์ผิด ตัวอักษรซ้ำ วรรณยุกต์/การันต์ผิด คะ/ค่ะ (ไทยและอังกฤษ) พร้อมแสดงว่าแก้ตรงไหน |
| 2. ปรับระดับภาษา | **สุภาพ · ทางการ · เป็นกันเอง** และเพิ่ม **วิชาการ · ธุรกิจ/อีเมลงาน** เลือกเพศผู้พูดได้ (ผม/ครับ, ดิฉัน/ค่ะ) |
| 3. แปลภาษา | ไทย ↔ อังกฤษ ด้วยโมเดลแปลเฉพาะทาง และแปลไทย ↔ จีน ญี่ปุ่น เกาหลี ฝรั่งเศส เยอรมัน สเปน เวียดนาม ลาว พม่า เขมร มลายู อินโดนีเซีย ด้วยโมเดลหลัก รองรับคำศัพท์บังคับ เลือกน้ำเสียง และแปลกลับเพื่อตรวจความหมาย |

ใช้งานได้ 2 แบบ: **หน้าเว็บบนเครื่อง** (`app.py`) และ **command line** (`cli.py`)

## วิธีทำงาน

```
ข้อความ ──► textassist.TextAssistant
              ├─ correct()   ─► โมเดลหลัก ─► ตัวกรอง: เก็บเฉพาะการแก้ตัวสะกด ─► ผล + จุดที่แก้
              ├─ rewrite()   ─► โมเดลหลัก ─► ปรับคำลงท้าย/สรรพนาม ─► ตรวจตัวเลขหาย
              └─ translate() ─► ไทย↔อังกฤษ: โมเดลแปล | ภาษาอื่น: โมเดลหลัก ─► ตรวจตัวเลขหาย
                                                     (ไม่มีโมเดล → โหมดพื้นฐานแบบกฎ สำหรับข้อ 1-2)
```

- โมเดลทำงานผ่าน [llama.cpp](https://github.com/ggml-org/llama.cpp) (`llama-cpp-python`) ไฟล์ GGUF แบบ 4-bit รันบน CPU ได้
- **โมเดลหลัก:** [Typhoon 2.1 Gemma3 4B](https://huggingface.co/typhoon-ai/typhoon2.1-gemma3-4b-gguf) ของ SCB 10X ฝึกมาเพื่อภาษาไทย (~2.5 GB)
- **โมเดลแปล:** [Typhoon Translate 1.5 4B](https://huggingface.co/typhoon-ai/typhoon-translate1.5-4b-gguf) แปลไทย ↔ อังกฤษโดยเฉพาะ (~2.5 GB)
- **ตัวเลือกคุณภาพสูง:** Typhoon 2.1 Gemma3 12B (~7.3 GB) แม่นกว่าแต่ช้ากว่า

### กลไกที่ช่วยให้ผลถูกต้อง
- **Prompt + ตัวอย่าง (few-shot)** แยกตามงาน ระดับภาษา เพศผู้พูด และภาษาของต้นฉบับ
- **แก้คำผิดแบบไม่เปลี่ยนความหมาย:** ถ้าโมเดลเปลี่ยนคำทั้งคำ (เช่น ลางาน → ลาหยุด) หรือตัดคำอย่าง "ไม่" ทิ้ง ระบบจะคืนคำเดิม เก็บไว้เฉพาะการแก้ตัวสะกด ถ้าโมเดลเขียนใหม่ทั้งย่อหน้า ระบบจะใช้โหมดพื้นฐานแทน
- **ปรับคำลงท้ายอัตโนมัติ:** ภาษาเป็นกันเอง/ทางการ/วิชาการ จะไม่มี ครับ/ค่ะ ภาษาสุภาพจะใช้ ครับ หรือ ค่ะ ตามเพศที่เลือก
- **ตรวจตัวเลข:** ถ้าวันที่ ราคา หรือเวลาในต้นฉบับหายไป ระบบจะเตือน
- **ข้อความยาว** ระบบแบ่งทีละย่อหน้าและคงรูปแบบบรรทัดเดิมไว้
- **แปลกลับ** (back-translation) ให้ผู้ใช้ตรวจว่าความหมายยังครบ
- **คำศัพท์บังคับ** (glossary) เช่น `ฝ่ายบุคคล = HR Department`

## ติดตั้ง (ทำครั้งเดียว ต้องต่ออินเทอร์เน็ต)

ต้องมี Python 3.10 ขึ้นไป และ RAM อย่างน้อย 8 GB (16 GB ถ้าใช้โมเดล 12B)

```bash
cd Text-Assistant-Offline
python -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate

# CPU (ใช้ได้ทุกเครื่อง ใช้ wheel สำเร็จรูป ไม่ต้องคอมไพล์)
pip install llama-cpp-python --prefer-binary --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu
pip install -r requirements.txt

# ดาวน์โหลดโมเดล (~5 GB) ไปที่โฟลเดอร์ models/
python download_models.py
# หรือเพิ่มโมเดล 12B ด้วย: python download_models.py --large
```

> ใช้การ์ดจอ NVIDIA: ติดตั้ง `llama-cpp-python` รุ่น CUDA (`--extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cu124`) แล้วตั้ง `TEXTASSIST_GPU_LAYERS=-1` จะเร็วขึ้นหลายเท่า
> Mac (Apple Silicon): `CMAKE_ARGS="-DGGML_METAL=on" pip install llama-cpp-python`

หลังจากนี้ **ตัดอินเทอร์เน็ตได้เลย** ระบบตั้งค่า `HF_HUB_OFFLINE=1` ไว้และไม่เรียกเครือข่ายตอนใช้งาน

## ใช้งาน

### หน้าเว็บ
```bash
python app.py
# เปิด http://127.0.0.1:7860
```
มี 3 แท็บ: แก้คำผิด (ขีดฆ่าคำผิด ไฮไลต์คำที่แก้) · ปรับระดับภาษา (เลือกได้หลายแบบพร้อมกัน) · แปลภาษา
หน้าเว็บไม่โหลดไฟล์จากภายนอก (ไม่มี CDN) จึงใช้ได้ทั้งตอนออฟไลน์

### Command line
```bash
python cli.py correct "ผมอยากกินข้าวมันไก่ที่ร้านนนั้นอร่อยมาก แต่วันนี้ร้านปิดเพาะเจ้าของไม่สะบาย"
python cli.py style "พรุ่งนี้กูไม่ไปทำงานนะ ป่วยว่ะ" --all --gender male
python cli.py style "พรุ่งนี้กูไม่ไปทำงานนะ ป่วยว่ะ" --style formal
python cli.py translate "พรุ่งนี้ผมขอลาป่วยหนึ่งวันครับ" --to en --back
python cli.py translate -f letter.txt --to ja --style formal
python cli.py translate "ติดต่อฝ่ายบุคคล" --to en --glossary '{"ฝ่ายบุคคล": "HR Department"}'
python cli.py status
```
เพิ่ม `--json` เพื่อรับผลแบบ JSON

### ใช้ในโค้ด Python
```python
from textassist import TextAssistant

ta = TextAssistant()
ta.correct("ขอบคุณนะค่ะ").text                     # 'ขอบคุณนะคะ'
ta.rewrite("กูหิวว่ะ", "polite", gender="female").text
ta.rewrite_all("กูหิวว่ะ")                         # {'polite': ..., 'formal': ..., 'casual': ...}
ta.translate("สวัสดีครับ", target="ja").text
```

## ตัวอย่างผลจริง (โมเดล 4B บน CPU 4 คอร์)

**แก้คำผิด**
| ต้นฉบับ | ผลลัพธ์ |
|---|---|
| ผมอยากกินข้าวมันไก่ที่ร้าน**นน**นั้นอร่อยมาก แต่วันนี้ร้านปิด**เพาะ**เจ้าของไม่**สะบาย** | ผมอยากกินข้าวมันไก่ที่ร้านนั้นอร่อยมาก แต่วันนี้ร้านปิด**เพราะ**เจ้าของไม่**สบาย** |
| ขอบคุณมาก**นะค่ะ** ที่ช่วย**อนุญาติ**ให้ดิฉันลางาน | ขอบคุณมาก**นะคะ** ที่ช่วย**อนุญาต**ให้ดิฉันลางาน |
| Thier meeting was postponed becuase of the wether. | Their meeting was postponed because of the weather. |

**ปรับระดับภาษา** ต้นฉบับ: *พรุ่งนี้กูไม่ไปทำงานนะ ป่วยว่ะ ฝากบอกหัวหน้าด้วย* (ผู้พูด: ชาย)
| แบบ | ผลลัพธ์ |
|---|---|
| สุภาพ | พรุ่งนี้ผมขอลาหยุดงานนะครับ เพราะไม่สบาย รบกวนช่วยแจ้งหัวหน้าให้ด้วยครับ |
| ทางการ | ข้าพเจ้าขอลาป่วยในวันพรุ่งนี้ จึงขอความกรุณาแจ้งให้ผู้บังคับบัญชาทราบด้วย |
| เป็นกันเอง | พรุ่งนี้เราไม่ไปทำงานนะ ป่วยอะ ฝากบอกหัวหน้าให้หน่อย |
| ธุรกิจ | พรุ่งนี้ผมขอลาป่วยหนึ่งวันครับ รบกวนช่วยแจ้งหัวหน้าให้ด้วยนะครับ |

**แปลภาษา**
| ต้นฉบับ | ผลลัพธ์ |
|---|---|
| กรุณาติดต่อฝ่ายบุคคลเพื่อขอใบรับรองเงินเดือน (glossary: ฝ่ายบุคคล = HR Department) | Please contact the HR Department to request a salary certificate. |
| Please submit the quarterly report by Friday. (→ ไทย, ทางการ) | กรุณาส่งรายงานประจำไตรมาสภายในวันศุกร์นี้ |
| ร้านนี้อาหารอร่อยและราคาไม่แพง (→ ญี่ปุ่น) | このお店の料理は美味しいですし、値段も手頃です。 |

ความเร็วโดยประมาณบน CPU 4 คอร์: 3-7 วินาทีต่อประโยค (โหลดโมเดลครั้งแรก ~5-10 วินาที)

## ข้อจำกัด
- โมเดล 4B อาจเปลี่ยนความหมายเล็กน้อยในการปรับระดับภาษา (เช่น ลากิจ → ลาหยุด) โดยเฉพาะข้อความที่เป็นทางการอยู่แล้ว ถ้าต้องการความแม่นยำสูงให้ใช้โมเดล 12B (`TEXTASSIST_GENERAL=general-large`) และตรวจทานก่อนใช้งานจริงเสมอ
- คำศัพท์เฉพาะทางมาก (กฎหมาย การแพทย์) ควรใส่ glossary
- โหมดพื้นฐาน (ไม่มีโมเดล) แก้ได้เฉพาะคำผิดที่พบบ่อยและแทนคำแบบง่าย และแปลภาษาไม่ได้

## ตั้งค่า (environment variables)
| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `TEXTASSIST_MODEL_DIR` | `./models` | โฟลเดอร์เก็บไฟล์โมเดล |
| `TEXTASSIST_GENERAL` | `general` | `general-large` = ใช้โมเดล 12B |
| `TEXTASSIST_GPU_LAYERS` | `0` | `-1` = ใช้ GPU ทุกชั้น |
| `TEXTASSIST_THREADS` | อัตโนมัติ | จำนวน CPU thread |
| `TEXTASSIST_CTX` | `4096` | ความยาว context |
| `TEXTASSIST_LOW_MEMORY` | `0` | `1` = เก็บโมเดลไว้ใน RAM ทีละตัว |

## โครงสร้างไฟล์
```
Text-Assistant-Offline/
├── app.py                 หน้าเว็บ (Flask, เปิดเฉพาะ 127.0.0.1)
├── cli.py                 command line
├── download_models.py     ดาวน์โหลดโมเดลครั้งเดียว
├── templates/index.html   หน้าเว็บ (ไม่มีไฟล์ภายนอก)
├── textassist/
│   ├── assistant.py       TextAssistant: correct / rewrite / translate
│   ├── prompts.py         prompt, ระดับภาษา, ตัวอย่าง, รายชื่อภาษา
│   ├── llm.py             โหลดและเรียกโมเดล GGUF ผ่าน llama.cpp
│   ├── textutil.py        ตรวจภาษา, ทำความสะอาดผล, diff, ตรวจตัวเลข, ปรับคำลงท้าย
│   ├── fallback.py        โหมดพื้นฐานแบบกฎ (ไม่ต้องมีโมเดล)
│   └── config.py          รายชื่อโมเดลและการตั้งค่า
└── tests/                 pytest (ใช้โมเดลจำลอง รันได้โดยไม่ต้องมีไฟล์โมเดล)
```

ทดสอบ: `python -m pytest -q tests`
