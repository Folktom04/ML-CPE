| B1 | ไม่อนุญาตตำแหน่ง → ขึ้น "ไม่ได้รับสิทธิ์ตำแหน่ง เลือกจังหวัดแทนได้" → ค้น "เชียง" → เชียงใหม่ → ทำขั้นที่เหลือจนจบ → หน้าหลักเป็น "จ.เชียงใหม่ (เลือกเอง)" และมีหมายเหตุ "ความแม่นยำนอกพื้นที่ปทุมธานียังไม่ได้ประเมิน" | | | | |
| B2 | ล้างข้อมูล → อนุญาตตำแหน่ง ("ขณะใช้แอป") → ทำแบบสอบถามผิว → สวิตช์ยินยอม**ปิดอยู่**และมีข้อความ "ส่งแค่ชื่อจังหวัด ไม่ส่งพิกัด GPS" → หน้าหลักเป็น "ตำแหน่งปัจจุบัน (GPS) · ใกล้ จ.… · ผิวประเภท …" และค่า UV ขึ้น | | | | |
| B3 | ถอนสิทธิ์ตำแหน่งของ UV Guard → ลากลงเพื่อโหลดใหม่ → ขึ้น "ไม่ได้รับสิทธิ์ตำแหน่ง จึงใช้จ.… แทน" และแอปยังใช้ได้ (จากนั้นให้คืนสิทธิ์) | | | | |

## E. ภาคสนาม (วัน 25) จดด้วยมือ เพราะแอปยังไม่มี export CSV และยังไม่มีตัวแยกกลางแดด/ในร่ม
วางมือถือหงายให้ขึ้น "ทิศทางถูกต้อง" แล้วรอประมาณ 2 วินาที (ค่า lux เป็น median ของ 2 วินาที) ค่า lux ยังไม่ได้ปรับเทียบและไม่เปลี่ยน UVI
UVI ของ Open-Meteo ให้ดูชั่วโมงเดียวกันที่ `https://api.open-meteo.com/v1/forecast?latitude=<lat>&longitude=<lon>&hourly=uv_index&timezone=Asia/Bangkok&forecast_days=1` (Open-Meteo รู้อยู่แล้วว่าให้ค่าต่ำกว่าจริง และค่าสูงสุดจะค้างอยู่แถว UVI 9.3)
