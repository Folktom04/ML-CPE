# คลิปรีวิวแอป UV Guard ทุกฟังก์ชัน — shot list และบทพากย์

ความยาวเป้าหมาย: ประมาณ 4 นาที · กำหนดส่ง: ก่อน 09:00 วันที่ 9 พ.ย. 2569

## เตรียมก่อนอัด

- **เวลาอัด:** 10:00–14:00 ของวันที่ 8 พ.ย. ช่วงนี้ UV สูง (พยากรณ์ปทุมธานี 8 พ.ย. สูงสุดประมาณ UVI 7.5 ตอน 12:00) จึงเห็นสีระดับ กราฟ และการ์ด "อยู่กลางแจ้ง" ชัดเจน ถ้าอัดตอนกลางคืน การ์ดหลายใบจะหายไป
- **เครื่องคอม:** เปิด API (`--host 0.0.0.0 --port 8000`) และ Metro แบบ dev client ที่ชี้ IP ของคอม แล้วเปิดแอปใหม่บนมือถือ เพื่อให้การ์ด "วางแผนกิจกรรมกลางแจ้ง" ขึ้นมา การ์ดนี้แก้แค่ JS จึงไม่ต้อง build แอปใหม่
- **มือถือ:**
  - เปิดโหมดห้ามรบกวน เพื่อไม่ให้มีแจ้งเตือนอื่นเด้งขึ้นมา
  - ตั้งความสว่างจอสูงสุด
  - ใช้ตัวอัดหน้าจอของ Android (ปัดแถบด่วนลงมา แล้วกด "บันทึกหน้าจอ") ไม่ต้องอัดเสียง เพราะเสียงพากย์จะอัดแยกทีหลัง
- **อัดทีละฉาก** ฉากละ 1 ไฟล์ แล้วตั้งชื่อ `s01.mp4`, `s02.mp4`, … ตามตารางด้านล่าง วางไว้ใน `docs/clip/raw/` (ไฟล์วิดีโอใหญ่ ห้าม commit)
- **เสียงพากย์ (ถ้าจะใส่):** อัดเสียงอ่านบทของแต่ละฉากด้วยแอปอัดเสียง แล้วตั้งชื่อ `v01.m4a`, `v02.m4a`, … ถ้าไม่อัดเสียง ผมจะใส่บทเป็นซับไตเติลแทน
- **ฉากแจ้งเตือน:** ใช้ภาพจากการทดสอบภาคสนามที่มีอยู่แล้ว (`docs/screenshots/09`, `10`, `12`) เพราะการแจ้งเตือน UV ≥ 8 อาจไม่เกิดในวันอัด (พยากรณ์สูงสุด 7.5)

## ข้อควรระวังตอนพูด

- ตัวเลข 0.48 UVI มาจาก `docs/test_2025_results.json` (NASA POWER 2025, n = 3,718)
- อย่าพูดว่าแอป "วัด" UV ให้พูดว่า "ประเมิน" เพราะไม่มีเครื่องวัด UV จริง
- ฉากถ่ายท้องฟ้า: ต้องบอกว่าผลจากภาพไม่เปลี่ยนค่า UV
- การ์ดวางแผนคิดจากกรณีอยู่กลางแดดตลอดและใช้ค่าบน ตัวเลขจึงเผื่อไว้มากกว่าจริง
