# บทพูดขาย UV Guard: "5 สิ่งที่คุณจะได้จาก UV Guard"

ความยาวประมาณ 60–70 วินาที (อ่านช้า ๆ ประมาณ 1 นาที) ใช้คู่กับคลิป `docs/clip/uv_guard_short.mp4` ได้ ช่อง "บนจอ" บอกฉากที่ควรขึ้นตอนพูด

| เวลา | บนจอ | พูด |
|---|---|---|
| 0:00–0:08 | หน้าหลัก ตัวเลข UV ใหญ่ | เคยไหม วันที่ฟ้าครึ้ม ๆ ไม่ร้อน แต่กลับบ้านมาหน้าแดง? เพราะแดดที่ทำร้ายผิวคือรังสี UV ซึ่งเรามองไม่เห็นและไม่รู้สึกร้อน วันนี้ขอแนะนำ UV Guard กับ 5 สิ่งที่คุณจะได้ |
| 0:08–0:18 | การ์ด UV + กราฟรายชั่วโมง | **หนึ่ง รู้ว่าแดดตรงที่คุณอยู่แรงแค่ไหน ตอนนี้และทุกชั่วโมงข้างหน้า** แอปใช้โมเดล Machine Learning ประเมิน UV ทดสอบกับข้อมูลดาวเทียมทั้งปี 2025 คลาดเคลื่อนเฉลี่ยแค่ 0.48 ซึ่งแม่นกว่าพยากรณ์อากาศทั่วไปที่คลาดเคลื่อน 1.24 |
| 0:18–0:28 | แบบสอบถามผิว → "อีก 29 นาทีผิวจะไหม้" | **สอง รู้ว่าผิวของคุณทนแดดได้กี่นาที** ตอบคำถาม 5 ข้อ แอปจะบอกเป็นนาทีว่าอีกนานเท่าไรผิวจะเริ่มแดง เพราะผิวแต่ละคนทนแดดได้ไม่เท่ากัน |
| 0:28–0:40 | วางแผนกิจกรรม → ตัวช่วยกันแดด → เปิด Shopee | **สาม วางแผนก่อนออกจากบ้าน** จะไปวิ่ง ว่ายน้ำ หรือเดินตลาด แอปบอกช่วงเวลาที่โดนแดดน้อยที่สุดและช่วงที่ควรเลี่ยง พร้อมแนะนำของกันแดดที่เหมาะกับวันนั้น แตะรูปแล้วไปร้านค้าได้ทันที |
| 0:40–0:50 | ภาพแจ้งเตือน | **สี่ มีคนคอยเตือนให้ แม้ไม่ได้เปิดแอป** ทั้งตอน UV สูงมาก ตอนใกล้ผิวไหม้ และตอนถึงเวลาทาครีมซ้ำ |
| 0:50–1:00 | ถ่ายฟ้า → ภาพระบายเมฆสีส้ม | **ห้า ถ่ายรูปท้องฟ้าให้ AI ดู** แอปบอกว่าเป็นเมฆแบบไหน เมฆอยู่ตรงไหนในภาพ และบอกว่าเมฆแบบนี้แปลว่าอะไรกับ UV เพราะเมฆบาง ๆ ยังปล่อย UV ผ่านลงมาได้เกือบทั้งหมด |
| 1:00–1:08 | ฉากปิด UV Guard | UV Guard ใช้แค่มือถือเครื่องเดียว ไม่ต้องซื้ออุปกรณ์เพิ่ม รู้ทันแดด ก่อนผิวไหม้ |

ข้อความท้ายจอ (ไม่ต้องพูดก็ได้ แต่ต้องขึ้นจอ): ค่าที่แอปแสดงเป็นการประเมินเพื่อการศึกษาและการเตือน ไม่ใช่การวินิจฉัยทางการแพทย์

## แบบสั้นมาก (ประมาณ 20 วินาที)

> UV Guard ให้คุณ 5 อย่าง: รู้ว่าแดดตรงที่คุณอยู่แรงแค่ไหน, รู้ว่าผิวคุณทนได้กี่นาที, รู้ว่าควรออกไปข้างนอกช่วงไหน, ได้แจ้งเตือนก่อนผิวไหม้ และถ่ายรูปฟ้าให้ AI ดูเมฆได้ ทั้งหมดในมือถือเครื่องเดียว รู้ทันแดด ก่อนผิวไหม้

## ข้อควรระวังตอนพูด

- ใช้คำว่า **"ประเมิน"** ไม่ใช่ "วัด" เพราะไม่มีเครื่องวัด UV จริง
- **0.48 กับ 1.24** คือความคลาดเคลื่อนเฉลี่ย (MAE, หน่วย UVI) เทียบกับ NASA POWER ปี 2025, n = 3,718 ชั่วโมง (ที่มา: `docs/test_2025_results.json`) ไม่ใช่การเทียบกับเครื่องวัดภาคพื้น
- **ถ่ายรูปท้องฟ้า** เป็นข้อมูลประกอบ ไม่เปลี่ยนค่า UV และไม่บันทึกภาพ ถ้ามีคนถามให้ตอบตามนี้
- **ร้านค้า** แอปไม่ได้ขายของเอง แค่ลิงก์ไปร้านค้า
- **"เมฆบางปล่อย UV ผ่านได้มาก"** เป็นความรู้ทั่วไปจากคู่มือดัชนี UV ของ WHO (2002)
