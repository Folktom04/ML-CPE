Lab: Troubleshoot เครือข่าย Layer 2 / Layer 3

วิธีใช้หน้าจอ
  • ไล่จากล่างขึ้นบน: link (Layer 1) → VLAN (Layer 2) → IP/route (Layer 3)
  • show ip interface brief ดูสถานะ link/admin ของ interface ที่มี IP
  • OSPF neighbor ไม่ขึ้นที่พบบ่อย: area ไม่ตรง, subnet ไม่ตรง, process/interface ไม่ได้เปิด
  • ping ผ่านแต่ไปไกลไม่ได้ ให้ดู show ip route ว่ามี route ไหม แล้วใช้ traceroute ดูว่าหยุดที่ hop ไหน

งานที่ต้องทำ

ผ่านบทเรียนนี้แล้ว ✓ ครบทุกข้อ
  1. หาสาเหตุแรก

    ping 192.168.20.10 ไม่ผ่าน ดูสถานะ interface vlan 20 (link/admin) ว่าเป็นอะไร

    ping 192.168.20.10 show ip interface brief
  2. แก้ gateway VLAN 20

    เปิด interface vlan 20 ให้ใช้งานได้ จน ping 192.168.20.10 ผ่าน

    configure terminal interface vlan 20 no shutdown exit ping 192.168.20.10
  3. เครื่องที่ 2 ยังไม่ผ่าน

    ping 192.168.20.11 ยังไม่ผ่าน หาว่า port 1/1/6 ผิดที่ไหนแล้วแก้

    show vlan show interface 1/1/6 interface 1/1/6 vlan access 20 exit
  4. OSPF neighbor หาย

    show ip ospf neighbors ไม่มี neighbor ดู config ของ 1/1/28 แล้วตอบว่าใช้ area อะไรอยู่

    show ip ospf neighbors show running-config interface 1/1/28
  5. แก้ OSPF

    แก้ area ของ 1/1/28 ให้ตรงกับ router (area 0) จน neighbor ขึ้น FULL

    interface 1/1/28 no ip ospf 1 area 0.0.0.1 ip ospf 1 area 0.0.0.0 exit show ip ospf neighbors
  6. ตรวจปลายทางสาขา

    ping 10.20.1.1 ให้ผ่าน และใช้ traceroute ดูเส้นทาง

    show ip route ping 10.20.1.1 traceroute 10.20.1.1
  7. บันทึก

    บันทึก config ที่แก้แล้ว

    end write memory
โจทย์ หลังมีคนแก้ config เมื่อวาน ผู้ใช้ VLAN 20 ออกนอกวงไม่ได้ และสาขา 10.20.0.0/16 ติดต่อไม่ได้ ให้หาสาเหตุทีละจุดแล้วแก้ (ข้อมูล: gateway VLAN 20 = 192.168.20.1, เครื่องทดสอบ 192.168.20.10 ที่ 1/1/5 และ 192.168.20.11 ที่ 1/1/6, router 10.0.0.6 ผ่าน 1/1/28 ใช้ OSPF area 0)
