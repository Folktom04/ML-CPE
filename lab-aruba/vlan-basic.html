วิธีใช้หน้าจอ
  • พิมพ์ ? เพื่อดูคำสั่งที่ใช้ได้ หรือพิมพ์ต่อท้ายคำ เช่น vlan ? เพื่อดูตัวเลือกถัดไป
  • กด Tab เพื่อเติมคำสั่งให้ครบ ใช้คำย่อได้ เช่น conf t, int 1/1/1, sh vlan
  • กด ↑ / ↓ เพื่อเรียกคำสั่งเดิม กด Ctrl+Z หรือพิมพ์ end เพื่อกลับไปโหมด switch#
  • เลือก port หลายตัวพร้อมกันได้ เช่น interface 1/1/1-1/1/4
  • คำสั่ง show ใช้ได้ทุกโหมด และวาง (paste) config หลายบรรทัดลงในหน้าจอได้

งานที่ต้องทำ

ผ่านบทเรียนนี้แล้ว ✓ ครบทุกข้อ
  1. ตั้งชื่อเครื่อง

    เข้าโหมด config แล้วตั้ง hostname เป็น SW-ACCESS-01

    configure terminal hostname SW-ACCESS-01
  2. สร้าง VLAN

    สร้าง VLAN 10 ชื่อ USERS และ VLAN 20 ชื่อ SERVERS

    vlan 10 name USERS exit vlan 20 name SERVERS exit
  3. Port ผู้ใช้ → VLAN 10

    กำหนด port 1/1/1–1/1/4 เป็น access port ของ VLAN 10

    interface 1/1/1-1/1/4 vlan access 10 exit
  4. Port server → VLAN 20

    กำหนด port 1/1/5–1/1/8 เป็น access port ของ VLAN 20

    interface 1/1/5-1/1/8 vlan access 20 exit
  5. Uplink เป็น trunk

    ตั้ง port 1/1/24 เป็น trunk โดยมี native VLAN 1 และอนุญาตเฉพาะ VLAN 10, 20

    interface 1/1/24 vlan trunk native 1 vlan trunk allowed 10,20 exit
  6. ปิด port ที่ไม่ใช้

    ปิด port 1/1/20 (shutdown) และใส่ description ว่า UNUSED

    interface 1/1/20 description UNUSED shutdown exit
  7. IP ของ VLAN 10

    สร้าง interface vlan 10 และตั้ง IP Address 192.168.10.1/24 (ใช้เป็น gateway ของผู้ใช้)

    interface vlan 10 ip address 192.168.10.1/24 exit
  8. ตรวจผลและบันทึก

    ตรวจด้วย show vlan และ show interface brief แล้วบันทึก config ด้วย write memory

    end show vlan show interface brief write memory
โจทย์ Switch ตัวใหม่ติดตั้งที่ชั้น 2 ของสำนักงาน port 1/1/1–1/1/4 ต่อเครื่องผู้ใช้ port 1/1/5–1/1/8 ต่อ server และ port 1/1/24 เป็น uplink ไปหา Core switch งานของคุณคือ config ให้พร้อมใช้งาน
